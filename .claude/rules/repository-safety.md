# 仓库与资料安全规则

本规则适用于所有文件、命令和 Git 操作。

- 不读取、输出、提交或传播密钥、Token、Cookie、登录态、`local/` 内容、私人组合/账本或其他本地资料。发现疑似凭证时停止并向用户说明，不把内容复制到报告或日志。
- 未经用户明确要求，不执行 `git commit`、`git push`、删除文件、移动历史成果、重写历史或会覆盖用户修改的命令。
- 执行 Git 操作前先运行 `git status --short`，需要远程操作时再运行 `git remote -v`；以当前仓库实际结果为准，不假设本机路径、remote 名称、默认分支或上游仓库存在。
- 编辑前检查目标文件；工作树中已有的未提交修改、删除和未跟踪文件不属于本任务时不得恢复、覆盖、暂存或清理。
- 研究报告、抽检结果和临时资料分离：发布目录只放用户要求保留的最终产出，临时下载、原始响应和中间 JSON 放在 `tmp/` 或本地忽略目录。
- 删除、覆盖或批量重命名前必须确认目标内容与任务描述一致；历史报告默认只读兼容，不为统一命名而迁移。
