# 主动基金研究：买基金就是买基金经理

对 $ARGUMENTS 进行主动基金（主动LOF/场外主动基金）投资研究。
核心分析对象是"基金经理"：能力圈、风格、言行一致、与持有人的利益一致。
买主动基金本质是把钱交给一个人管——段永平"买股票就是买人"、
李录"投资的本质是投人"的直接延伸。

**支持输入格式**：基金代码（LOF如 161725 / 场外如 012414.OF）、基金名称（先 fundsearch 查代码）

## 适用场景

- 看好某行业/风格但认为被动指数买不到超额，需要选人
- 持仓基金定期体检（经理换人/风格漂移/规模膨胀）
- 与 /index-fund-research 对比：被动买指数 vs 主动买经理
- 新基金认购/申购前的尽调

## 设计理念

主动基金净值 = 经理能力 + 运气 + 市场β 的混合体。研究结构与个股同构：

- **经理 = 管理层**：复用 /management-deep-dive 的"承诺vs兑现/困难时期/资本配置"框架，对象换成基金经理
- **持仓 = 业务组合**：季报前十大是经理思想的唯一公开证据
- **持有人 = 股东**：申赎行为与持有人结构决定你与谁同船

核心三问：
1. 经理在能力圈内做事吗？
2. 说的和做的（持仓）一致吗？
3. 愿意把钱交给这个人管10年吗？

### 前置步骤：AI研究偏见自觉（必须执行）

| 偏见 | 表现 | 应对 |
|------|------|------|
| 业绩回望偏差 | 过去3年翻倍=未来翻倍 | 分年度拆超额来源，警惕风格β（牛市β伪装成alpha） |
| 幸存者偏差 | 只见活下来的基金 | 查同策略基金清盘记录 |
| 冠军魔咒 | 明星基金规模暴涨后业绩下滑 | 规模/策略容量定量评估 |
| 风格漂移 | 嘴上价值投资实际追热点 | 持仓风格与宣称策略逐期比对 |
| 归因模糊 | 牛市里谁都是股神 | 用相对基准超额而非绝对收益评判 |

### 第一步：基金与经理基本盘

> **数据源规范**：唯一数据入口是 [.claude/skills/financial-data/SKILL.md](../../skills/financial-data/SKILL.md) 规定的统一数据访问层 `tools/data_loader.py`；职责（查代码、读基金基本盘、份额、经理档案）不再内嵌命令。

```bash
uv run python tools/data_loader.py get fund {code} --field basic    # 基本盘（类型/费率/基准/经理）
uv run python tools/data_loader.py get fund {code} --field shares   # 规模与份额变动
uv run python tools/data_loader.py get fund {code} --field manager  # 历任经理档案
uv run python tools/data_loader.py search {基金名/代码}              # 查代码（基金+指数分节）
```

该基金数据缺失/无权限时，按 financial-data 备用来源（天天基金持仓/经理/持有人页）人工核查，并在报告中标注"副源补齐"。

输出"基金与经理基本盘"表：基金类型/成立日/业绩基准/综合费率/最新规模/现任经理及**任职起始**/历任经理表。

关键判断：**区分"真经理"与"挂名"**（多经理基金谁在主导，看简历与过往业绩归属）；**任期<3年样本不足**，必须降低结论置信度。

### 第二步：经理画像

**2.1 任职期业绩**（从任职日算起，避免把前任业绩记到现任头上）：
```bash
uv run python tools/data_loader.py get fund {code} --field nav     # 净值与区间收益（复权口径）
```
输出：任职以来年化收益/最大回撤/分年度超额（相对业绩基准，基准见 basic）。

**2.2 风格定位**：持仓市值/行业 → 大/小盘、价值/成长；前十大用 /quality-screen 7条指标快速过一遍，判断持仓质量。

**2.3 持仓集中度**：`data_loader get fund {code} --field holdings` 前十大占比（无权限→天天基金持仓明细页）；单一重仓上限、行业集中度。

**2.4 换手率与言行一致**：换手率（tushare 无接口，天天基金/韭圈儿副源）；季报持仓变化 vs 经理公开策略表述逐期比对。
**段永平式追问**：经理的能力圈是什么？持仓里有没有超出能力圈的动作（比如价值派买题材）？

### 第三步：持仓分析

`data_loader get fund {code} --field holdings` 前十大 + 行业暴露表：

| # | 个股 | 代码 | 占净值比 | 生意一句话 | 质量快筛 | 是否已有研究 |
|---|------|------|---------|-----------|---------|------------|

重仓股质量存疑时链 /investment-research 深挖。
**巴菲特式追问**：经理明天离职，这个组合还值得持有吗？——质量依赖经理个人还是投研体系？

### 第四步：基金产品体检（共享清单见 financial-data.md）

按 `.claude/skills/financial-data/SKILL.md`"基金产品体检指标清单"逐项检查：

- **费率**：综合费率 vs 同类中位数（主动 ≤1.5%）
- **规模**：>100亿警惕策略容量（大市值风格影响小，小盘/主题风格影响大）
- **申赎与限购**：大额限购 = 规模管理的正面信号（天天基金副源）；连续大额赎回注意流动性风险
- **持有人结构**：`data_loader get fund {code} --field holder` 或天天基金副源——机构占比上升 = 机构认可信号
- **分红记录**：与合同约定一致（天天基金）
**芒格式追问**：什么情况下我会被迫退出？（经理离职/风格漂移/规模失控/大幅回撤）先把退出条件写下来。

### 第五步：结论——经理能力圈判断 + 买入条件

段永平"对的人"三问表：

| 一问 | 判断 | 证据 |
|------|------|------|
| 正直（说的=做的） | | |
| 有能力（能力圈内+超额可归因） | | |
| 愿托付10年（任职稳定+规模健康） | | |

| 决策项 | 结论 |
|--------|------|
| 买入条件清单 | 持仓平均估值分位、经理任职稳定性、规模健康度 |
| 监控指标 | 经理变更/季报漂移/规模超阈值/连续落后基准 |

**李录式追问**：经理的能力圈依附平台还是个人？他离任后体系能复制他的业绩吗？

## 输出要求

1. 中文、直接犀利、不说废话；数据标来源，主源合理性校验（见 [financial-data 规范](../../skills/financial-data/SKILL.md)）
2. 计算一律走工具（data_loader 取数 / financial_rigor.py 验算），禁止LLM心算
3. 报告开头：信息丰富度评级（A/B/C）+ AI研究局限性声明；结尾区分"AI分析置信度"与"投资确定性"
4. 输出路径以 [.claude/rules/report-output.md](../../rules/report-output.md) 路由表为准。

## 数据抽检（准出流程）

```bash
uv run python tools/report_audit.py extract --report {报告路径}   # 15%随机抽检
```
【准出】全部≤1%偏差；【打回】修正后重审。

## 关键原则与局限性

- 持仓与净值低频披露（季报/日更）有滞后；业绩归因无法完全剥离运气
- **至少3年+穿越牛熊**的样本才能谈业绩；本 skill 只做单只深度研究，不做全市场基金筛选
- 经理离职是最常见的逻辑破坏事件，研究结论必须写明"经理变更即重审"
- 规模是主动基金的天敌：明星效应带来的规模膨胀会稀释超额收益
- 基金细粒度接口（fund_manager/fund_portfolio 等）可能无权限 → data_loader 会走备用来源，报告中标注"副源补齐"，不再依赖单一接口可用性
