# 单公司分析标准工作流（Stock Pipeline）

对 `$ARGUMENTS` 执行单家公司的标准分析流水线。**本 Skill 是编排器**——自身不产出独立报告，只按阶段调度现有 Skill、在用户决策点停下来确认，并在阶段间提示读取已生成报告。

**核心原则**：低成本阶段先跑，高成本阶段只在用户确认后推进；每阶段产出落盘到报告路由规则指定位置，供下一阶段复用。

---

## 阶段机总览

```
阶段0 定位（低成本）→ 阶段1 深入研判（高成本）→ 阶段2 买入把关 → 阶段3 买入后跟踪（长期）
```

每个阶段结束有一个**用户决策闸门**：只有确认通过/值得才进入下一阶段。

---

## 阶段0：定位（低成本）

选一个入口（根据输入与目标）：

| 情况 | 用 | 说明 |
|------|-----|------|
| 批量/首次/多家 | `/quality-screen` | 7 硬指标去劣，适合先排除确定不好的 |
| 单家且近边界/需快速六关 | `/investment-checklist` | 六关判断是否值得深入 |

**阶段0 输出**：通过/排除/灰色结论。各公司结果写入对应 `reports/01-单公司分析/{公司}/`。

**决策闸门**：
- ❌ 排除 → 记录排除原因，**结束**（不再进入阶段1）。
- ⚠️ 灰色 → 与用户确认：是否仍要深研（信息稀缺/成长型公司常在此被 check 掉却值得深挖）。
- ✅ 通过 → 进入阶段1。

---

## 阶段1：深入研判（**高成本，须用户确认后执行**）

> 不要对阶段0 通过的每家公司自动跑全量深研。**先向用户展示阶段0 结论，确认"这家值得深入"再继续。**

| 情形 | 用 | 说明 |
|------|-----|------|
| 一般深度研究 | `/investment-research` | 单视角四大师框架 |
| 最快最全面 | `/investment-team` | 4 并行 Agent，最适合核心标的 |
| 管理层为核心变量 | `/management-deep-dive` | investment-research 第五步的深化版 |
| 未上市公司 | `/private-company-research` | 多源拼图 + 置信度标注 |

输出落到 `reports/01-单公司分析/{公司}/`（报告文件名见 [报告路由规则](../../rules/report-output.md)）。`/investment-team` 产出四个视角 + 最终报告，供 thesis-tracker 填论文基线复用。

**跨阶段分支（财报季）**：若当前处于公司财报期，建议补 `/earnings-review`（快速单视角）或 `/earnings-team`（重要公司 + 公众号发布）；深耕一手财报。

**决策闸门**：问用户——"研究结论是否支持买入/持仓？"据此决定进入阶段2 或仅存论文基线观察。

---

## 阶段2：买入前把关

- 若阶段0 用的是批量 `/quality-screen`（未做六关），此处用 `/investment-checklist` 补六关 + 镜子测试。
- 结合阶段1 的估值、安全边际、管理层判断，给出明确买入/不买/观望结论。

**决策闸门**：
- 买入 → 进入阶段3 建论文。
- 观望/不买 → 仍可建论文基线（`/thesis-tracker` 支持无持仓基线），便于后续跟踪。

---

## 阶段3：买入后跟踪（长期，跨阶段分支触发）

| 触发 | 用 | 说明 |
|------|-----|------|
| 买入/建立基线 | `/thesis-tracker` | 建 5 句论文 + 假设/红线/估值锚点，读阶段1 报告填基线 |
| 财报季 | `/earnings-review` 或 `/earnings-team` | 精读一手财报，对照论文假设 |
| 持仓股价异动（单日 ±5%/一周 ±10%） | `/news-pulse` | 10 分钟归因，判断是否基本面驱动 |
| 收益性持仓 | `/income-investment` | 评估分配收益的可持续性 |
| 论文可能漂移 | `/thesis-drift` | 对比旧/新快照，区分事实/估值/措辞变化 |
| 组合层面 | `/portfolio-review` | 持仓与集中度、机会成本 |

---

## 跨阶段分支触发规则

1. **财报季**：阶段1 后若公司在本财报期，主动建议财报精读；买入后每季度财报都走阶段3 的 earnings 分支。
2. **持仓异动**：任意阶段若股价单日 ±5% 或一周 ±10%，暂停当前节奏，先 `/news-pulse` 归因，再决定是否重审论文。
3. **论文漂移**：每次 thesis-tracker 检查产生新快照后，定期比对新旧快照确认无隐性漂移。

---

## 输出与路由

- 本 Skill 自身不产出独立报告；各阶段由被调用的 Skill 按 [报告路由规则](../../rules/report-output.md) 落盘到 `reports/01-单公司分析/{公司}/`。
- 阶段间需要读取上一阶段产物时，从该目录读取（`/investment-team` 的最终报告、`/earnings-review` 的财报精读等）。
- 不复制路由：以 `.claude/rules/report-output.md` 为唯一输出路径来源。
- 数据获取遵守 `.claude/skills/financial-data/SKILL.md`（统一走 `tools/data_loader.py`）。
