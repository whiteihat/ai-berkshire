# 公告落盘功能 — 轻量计划

---

## 一、需求

为报告生成提供上市公司公告元数据（标题、日期、类型、链接），便于：

- 在 investment-research / news-pulse 等 Skill 中查找最新公告、大事
- 按时间/类型筛选关键公告（年报、业绩预告、重大事项等）
- 不需要全文存储，需要时按 URL 获取 PDF 原文

## 二、数据源

**东方财富公告 API**（免费，无需 token，无需注册）

```
GET https://np-anotice-stock.eastmoney.com/api/security/ann
参数：
  stock_list    — 股票代码（纯数字，如 600938）
  page_size     — 每页条数（最大 50）
  page_index    — 页码
  ann_type      — A（全部）
  f_node / s_node — 筛选节点（0=全部）
```

返回字段：`title`、`notice_date`、`art_code`（公告唯一ID）、`columns`（类型）等。

**备选**：巨潮资讯网（cninfo.com.cn）POST API（tmp_fetch_ann.py 已验证可用）。

## 三、存储设计

### 目录位置

```
local/{ts_code}_{name}/
├── raw/
│   ├── financial/          # 已有
│   ├── daily/              # 已有
│   ├── meta/               # 已有
│   └── announcements.json  # 新增：公告元数据
└── manifest.json           # 已有：增加 anns 字段
```

**为什么不用单独的 announcements/ 目录？**

- 打破已有的 `local/{ts_code}_{name}/` 一一对应结构
- 公告是公司维度的数据，跟着公司走最合理
- 一个 JSON 文件比几十个文件好管理

### announcements.json 格式

```json
[
  {
    "art_code": "AN202608181828108820",
    "title": "中国海油：中国海洋石油集团有限公司关于2026年度业绩说明会的公告",
    "notice_date": "2026-08-19",
    "columns": "业绩说明会",
    "url": "https://data.eastmoney.com/notices/detail/600938/AN202608181828108820.html"
  },
  ...
]
```

字段说明：

| 字段            | 说明                             |
| --------------- | -------------------------------- |
| `art_code`    | 东方财富公告唯一ID（去重键）     |
| `title`       | 公告标题                         |
| `notice_date` | 发布日期（YYYY-MM-DD）           |
| `columns`     | 公告类型（年报/中报/临时公告等） |
| `url`         | 公告详情页URL（按需获取原文）    |

### manifest.json 新增字段

```json
{
  "ts_code": "600938.SH",
  "name": "中国海油",
  "last_fetch": "...",
  "periods": { ... },
  "metadata": { ... },
  "announcements": {
    "last_fetch": "2026-08-23",
    "count": 25,
    "latest_date": "2026-08-19"
  }
}
```

## 四、实现方案

### 方案 A：集成到 fundamental_fetcher.py（推荐）

在 `fetch_stock()` 中增加第 5 步：拉取公告。

```python
# 第 5 步：公告列表
logging.info("\n[5/5] 公告列表")
ann_path = os.path.join(stock_dir, "raw", "announcements.json")
if not (skip_existing and os.path.exists(ann_path)):
    anns = _fetch_eastmoney_anns(ts_code_6, limit=30)
    if anns:
        _save_json(anns, ann_path)
        manifest["announcements"] = {
            "last_fetch": datetime.now().strftime("%Y-%m-%d"),
            "count": len(anns),
            "latest_date": anns[0]["notice_date"] if anns else None,
        }
```

优点：一个命令搞定全部数据，不需要额外操作。
缺点：fetch_stock 会多一次网络请求（~1s）。

### 方案 B：独立命令

```bash
python tools/fundamental_fetcher.py anns 600938 中国海油       # 拉取公告
python tools/fundamental_fetcher.py anns 600938 中国海油 --limit 50  # 指定条数
```

优点：灵活，可以单独更新公告。
缺点：多一个命令。

### 推荐：方案 A + B 结合

- `fetch_stock()` 默认包含公告拉取（方案 A）
- 同时支持独立 `anns` 命令（方案 B），用于单独更新

## 五、增量更新策略

- 检查 `manifest.announcements.latest_date`
- 请求时带上 `page_size=50`（足够覆盖近期公告）
- 比对 `art_code` 去重，只新增不覆盖
- 每次全量替换 JSON 文件（公告列表本身不大，50 条 ~20KB）

## 六、读取接口

```python
def load_announcements(ts_code_6, name, limit=20):
    """读取最近 N 条公告"""
    path = os.path.join(_LOCAL_DIR, f"{ts_code_6}_{name}", "raw", "announcements.json")
    if not os.path.exists(path):
        return []
    with open(path, "r", encoding="utf-8") as f:
        anns = json.load(f)
    return anns[:limit]
```

## 八、关键约束

1. **不下载 PDF**：只存元数据 + URL，需要时按 URL 获取
2. **去重**：以 `art_code` 为唯一键
3. **限流**：每次请求间隔 0.75s（复用已有限流器）
4. **编码**：Windows 控制台中文乱码不影响数据存储（JSON 内部 UTF-8 正常）
5. **不依赖 Tushare**：公告接口走东方财富免费 API，不消耗 Tushare 积分
