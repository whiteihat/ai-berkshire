## 使用说明

每个指标按以下结构讲解：

```
指标定义 → 用到的原始报表 → 变量推导 → 完整公式 → 经济含义 → 筛选阈值
```

**三大报表速查**（后续反复引用）：

| 报表 | 核心等式 | 回答的问题 |
| :--- | :--- | :--- |
| **利润表** | 收入 – 费用 = NI | 这段时间赚了多少钱？ |
| **资产负债表** | 资产 = 负债 + 股东权益 | 这个时点拥有什么、欠了什么？ |
| **现金流量表** | OCF + 投资现金流 + 筹资现金流 = 净现金变动 | 钱从哪来、花到哪去？ |

> **贯穿全文的核心关系**：利润表遵循 **权责发生制**（交易发生即确认），现金流量表遵循 **收付实现制**（现金收付才确认）。两者之间的差异，是理解财务质量的钥匙。

**适用前提**：本手册推导基于 **CAS**。若分析 **IFRS** 或 **US GAAP** 公司，需先阅读报表附注中的"现金流量表编制基础"，确认利息收入/股息的科目归属（部分准则将其归入投资活动而非经营活动），必要时做科目重分类调整后再代入公式，否则 OCF 与 FCF 数值将出现口径偏差。


## 指标一：10年平均ROE（净资产收益率）

### 1.1 定义与公式

**ROE（Return on Equity，净资产收益率）** 衡量股东每投入1块钱能赚回多少利润：

$$\text{ROE} = \frac{\text{NI}}{\text{股东权益}}$$

其中，**NI（Net Income，净利润）** 取自利润表的"归属于母公司所有者的净利润"，**股东权益**取自资产负债表的"所有者权益合计"扣除"少数股东权益"。

### 1.2 变量推导

- **NI（净利润）** 的推导路径：

```
营业收入 – 营业成本 = 毛利润
毛利润 – 销售费用 – 管理费用 – 研发费用 – 财务费用 = 营业利润
营业利润 ± 营业外收支 = 利润总额
利润总额 – 所得税费用 = NI
```

- **股东权益** 的构成：

```
股东权益 = 实收资本（股本）+ 资本公积 + 盈余公积 + 未分配利润
```

- **时点与期间的匹配**：NI 是"期间"值（如2025全年），股东权益是"时点"值（如2025/12/31）。本手册采用**平均法**，分母取（期初股东权益 + 期末股东权益）÷ 2，以消除分红或增发的时点扭曲。

### 1.3 10年平均与杜邦分解

$$\text{10年平均ROE} = \frac{ROE_1 + ROE_2 + \cdots + ROE_{10}}{10}$$

**ROE 的杜邦分解**（理解高质量ROE的来源）：

$$ROE = \underbrace{\frac{\text{NI}}{\text{收入}}}_{\text{净利率}} \times \underbrace{\frac{\text{收入}}{\text{总资产}}}_{\text{资产周转率}} \times \underbrace{\frac{\text{总资产}}{\text{股东权益}}}_{\text{权益乘数（杠杆）}}$$

高质量的 ROE 应来自高净利率（品牌溢价）或高周转率（运营效率），而非高权益乘数（单纯加杠杆）。若 ROE 高且资产负债率 > 70%，应标记为"杠杆驱动型"，在评估中打折——单纯的高杠杆不是竞争优势，而是风险放大器。

### 1.4 筛选阈值

**阈值：10年平均ROE < 8% → 排除**。8%约为长期国债收益率（2.5-3%）的2倍，代表股东资本的机会成本底线。取10年均值是为了过滤行业周期波动。


## 指标二：5年累计自由现金流（FCF）

### 2.1 定义与公式

**FCF（Free Cash Flow，自由现金流）** 是公司经营赚到的真金白银，在扣除维持生意所需的再投资后，可自由分配给股东的现金：

$$\text{FCF} = \text{OCF} – \text{CapEx}$$

其中 **OCF（Operating Cash Flow，经营活动现金流）** 和 **CapEx（Capital Expenditure，资本性支出）** 均取自现金流量表。

### 2.2 变量推导

- **OCF** 从 NI 出发调整而来：

```
NI
  + 折旧与摊销（非现金费用）
  + 资产减值损失（非现金）
  ± 经营性应收项目的变动（应收增加→扣减）
  ± 经营性应付项目的变动（应付增加→加回）
  ± 存货的变动（存货增加→扣减）
= OCF
```

- **CapEx** 是"购建固定资产、无形资产和其他长期资产支付的现金"（取绝对值）。**绝对禁止**用"投资活动现金流净额"代替 CapEx，因为后者含理财买卖、处置子公司等非经营项目，会严重扭曲真实 FCF。

**维护性 CapEx 与扩张性 CapEx**：前者是维持现有产能的最低投入（如更换老旧设备），后者是扩大产能的额外投入（如建新工厂）。本手册采用**保守口径**，全部 CapEx 均扣减，得到的 FCF 称为**保守 FCF**。若需区分，可阅读年报"管理层讨论"或"在建工程"附注，仅扣减维护性部分，得到的 FCF 称为**核心 FCF**。核心 FCF 反映公司在维持现有产能后的剩余现金生成能力，是判断生意本质的关键口径。若核心 FCF 为正而保守 FCF 为负，表明公司处于高投入成长期，不构成致命缺陷。

### 2.3 新租赁准则（IFRS 16 / ASC 842）下的调整

新准则将经营租赁租金拆分为"利息部分"（仍在 OCF）和"偿还租赁负债本金"（移至筹资活动）。**重租赁公司（如零售、航空、梯媒）的 OCF 因此被高估**。

**调整公式**（仅针对重租赁公司）：

$$\text{调整后 FCF} = \text{OCF} + \text{偿还租赁负债本金} – \text{CapEx}$$

### 2.4 5年累计与筛选阈值

$$\text{5年累计FCF} = FCF_{Y1} + FCF_{Y2} + FCF_{Y3} + FCF_{Y4} + FCF_{Y5}$$

**阈值：5年累计FCF为负 → 排除**。连续5年不产生真实现金，意味着公司必须靠外部融资（发债或增发）续命，长期不可持续。


## 指标三：利息覆盖倍数

### 3.1 定义与公式

**利息覆盖倍数** 衡量公司营业利润能够覆盖利息支出的次数，反映偿债安全性：

$$\text{利息覆盖倍数} = \frac{\text{EBIT}}{\text{利息费用}}$$

**EBIT（Earnings Before Interest and Taxes，息税前利润）** 的简化算法：EBIT = NI + 所得税 + 利息费用。

### 3.2 变量推导与重资产行业补充

**为什么要用 EBIT 而非 NI？** 利息是债务成本，必须用"扣利息之前"的利润来衡量偿付能力。若用 NI 除以利息，等于用"还完利息剩下的钱"去衡量"还利息的能力"，逻辑循环。

利息费用取"财务费用"中的"利息支出"部分（仅限有息负债，不含应付账款等经营负债）。

**净现金公司处理**：若公司账上现金远超有息负债，导致"利息费用"≤ 0（即净利息收入），则本指标自动视为无穷大，直接通过，无需计算。

**重资产行业补充**：对于折旧摊销极大的公司（航空、电信、重工业），建议同步计算 **EBITDA / 利息**。**EBITDA（Earnings Before Interest, Taxes, Depreciation and Amortization，息税折旧摊销前利润）** = EBIT + 折旧 + 摊销。之所以用 EBITDA 而非 EBIT，是因为还本付息靠的是现金而非会计利润——折旧是利润表上的费用但不产生现金流出，加回来才更接近"公司实际可用于偿债的现金来源"。EBITDA 覆盖倍数通常高于 EBIT 覆盖倍数，提供更强的安全边际参考。

### 3.3 筛选阈值

**阈值：利息覆盖倍数 < 2倍 → 排除**。低于2倍意味着利润下降一半即无法付息，经济下行时极易触发债务危机。

**银行业例外**：银行的本质是利差经营，利息支出是主营业务成本而非负债成本。本指标对金融业不适用，应跳过，改用资本充足率、不良贷款率等专属指标。


## 指标四：长期毛利率

### 4.1 定义与公式

**毛利率** 衡量每1元收入扣除直接成本后剩余的比例，反映定价权：

$$\text{毛利率} = \frac{\text{收入} – \text{COGS}}{\text{收入}} \times 100\%$$

### 4.2 变量推导与含义

- **收入**：利润表第一行（权责发生制，注意赊账陷阱——收入确认不等于收到现金）。
- **COGS（Cost of Goods Sold，营业成本）** ：与生产/服务直接相关的成本（制造业的原材料与人工、零售业的采购成本、软件业的服务器成本）。销售费用与管理费用不在此列，因此不影响毛利率但影响净利率。

毛利率越高，定价权越强。长期均值通常取 **5年平均值**。

### 4.3 毛利率 vs 净利率

毛利率衡量"产品/服务本身的赚钱能力"，净利率衡量"整家公司最终的赚钱能力"。两者之间的差额是销售费用、管理费用、研发费用、财务费用和税。一家公司可以毛利率很高但净利率很低（如药企研发费用极高），也可以毛利率低但净利率不低（如 Costco 靠会员费而非商品加价赚钱）。

三种典型的费用结构模式：

| 类型 | 毛利率 | 费用特征 | 净利率 | 典型公司 |
| :---: | :---: | :--- | :---: | :--- |
| 高毛利+低费用 | 高 | 几乎不需要销售/管理费用 | 高 | 白酒、广告媒体 |
| 高毛利+高费用 | 高 | 研发或销售费用极高 | 中等 | 医药（研发重）、奢侈品（营销重） |
| 低毛利+低费用 | 低 | 薄利但极精简运营 | 低-中 | Costco、拼多多 |

### 4.4 筛选阈值与行业例外

**阈值：长期毛利率 < 15% → 排除**。低于15%意味着直接成本占收入85%以上，剩余部分极难覆盖费用和税，经济下行时极其脆弱。

**行业例外**：
1. **金融业（银行/保险）**：无传统"营业成本"，跳过本指标。
2. **高周转零售业（Costco、拼多多等）**：毛利率虽低（12-15%），但利润来源于周转效率和平台抽成。若同时满足本文档【决策优先级矩阵】Lv.4 的量化标准（ROE > 20%、核心FCF占比 > 80%、OCF/NI > 1.2），可豁免本阈值。


## 指标五：经营现金流 / 净利润（OCF/NI）

### 5.1 定义与公式

**OCF/NI** 衡量账面利润的"含金量"——每1元利润转化成了多少真实现金：

$$\text{OCF/NI} = \frac{\text{OCF}}{\text{扣非归母净利润}}$$

分母必须使用 **"扣除非经常性损益的归母净利润"**（简称扣非净利润），而非普通归母净利润。因为政府补贴、资产处置等一次性收益会虚增 NI，导致比值被错误压低。

> 例：某公司正常经营利润30亿，当年卖楼赚20亿（非经常性），NI变成50亿。OCF仅33亿。OCF/NI = 33/50 = 0.66 → 看似"利润质量差"。实际主业 OCF/NI = 33/30 = 1.1 → 完全正常。

### 5.2 极端情况处理

若 **扣非净利润为负**，但 **OCF 为正**（常见于折旧极大的重资产行业或转型期公司），则本指标跳过（标记为"观察项"），不视为淘汰依据，应结合 FCF 和 ROE 综合判断。

### 5.3 比值的经济含义

| OCF/NI 范围 | 信号 |
| :---: | :--- |
| > 1.0 | ✅ 利润质量高，现金转化好 |
| 0.8 – 1.0 | ✅ 基本匹配，正常 |
| 0.5 – 0.8 | ⚠️ 警惕：可能存在大量应收款或存货积压 |
| < 0.5 | 🔴 危险：利润可能是"纸面富贵" |
| < 0 | 🔴 严重：主业不产生现金 |

OCF 经常 > NI 的主要原因是非现金的**折旧与摊销**被加回；OCF < NI 则常见于**应收账款激增、存货积压或预付款增加**。

### 5.4 筛选阈值

**阈值：OCF/NI（5年均值）< 0.7 → 排除**。长期低于0.7意味着超过30%的利润未转化为现金，利润质量存疑。


## 指标六：长期净利率

### 6.1 定义与公式

**净利率** 衡量每1元收入最终能留下多少纯利，反映综合抗风险能力：

$$\text{净利率} = \frac{\text{NI}}{\text{收入}} \times 100\%$$

### 6.2 从毛利率到净利率的损耗链

```
收入 （100%）
  – COGS
= 毛利润（毛利率）
  – 销售费用 – 管理费用 – 研发费用 – 财务费用
  ± 投资收益 ± 营业外收支
  – 所得税
= NI（净利率）
```

### 6.3 筛选阈值与行业例外

**阈值：长期净利率 < 5% → 排除**。低于5%意味着收入只要波动5%（极常见），利润即归零，毫无缓冲空间。

**行业例外**（同指标四）：
- **金融业**：跳过本指标。
- **高周转零售业**：若同时满足决策矩阵 Lv.4 的量化标准（ROE > 20%、核心FCF占比 > 80%、OCF/NI > 1.2），可豁免本阈值。


## 指标七：5年总股本膨胀

### 7.1 定义与公式

**股本膨胀率** 衡量5年内股东持股被稀释的程度：

$$\text{股本膨胀率} = \frac{\text{当前总股本} – \text{调整后5年前总股本}}{\text{调整后5年前总股本}} \times 100\%$$

### 7.2 前复权调整（关键前提）

若期间发生送红股或资本公积转增股本，必须将5年前的股本按相同比例回溯调整（前复权），否则会误判。

**示例**：公司2023年"10送10"，报表总股本从100亿变200亿。直接算膨胀100%（❌ 误杀）。正确做法：将5年前的100亿按送股比例×2调整为200亿，再与当前200亿对比，膨胀率为0%（✅ 零稀释）。

**调整方法**：查阅历年"股本变动表"，将所有送转比例连乘，调整基期股本：

$$\text{调整后5年前股本} = \text{报表5年前股本} \times \prod_{i=1}^{n}(1 + \text{第i次送转比例})$$

### 7.3 经济含义与筛选阈值

$$\text{EPS（Earnings Per Share，每股收益）} = \frac{\text{归母NI}}{\text{总股本}}$$

股本膨胀直接摊薄 EPS。若膨胀20%而 NI 不变，EPS 即下降16.7%。

**阈值：5年总股本膨胀 > 20%（非并购原因）→ 排除**。非并购原因的增发，说明公司赚的钱不够花，需要向股东伸手，是对老股东利益的侵蚀。

| 膨胀率 | 判断 |
| :---: | :--- |
| 0% | ✅ 最佳 |
| 0-10% | ✅ 可接受 |
| 10-20% | ⚠️ 需检查原因 |
| > 20%（非并购） | ❌ 排除 |

## 去劣筛选决策优先级矩阵

实战中指标可能冲突，按以下 **Lv.1 → Lv.5 逐级裁决**，高优先级锁定后低优先级不再推翻：

| 优先级 | 指标 | 规则 |
| :---: | :--- | :--- |
| **Lv.1（铁律）** | **② 5年累计FCF（核心口径）** | 若核心FCF（仅扣维护性CapEx）5年累计为**负**，**直接排除**，不予豁免。 |
| **Lv.2（铁律）** | **⑤ OCF/NI（5年均值）** | 若 **< 0.4**，**直接排除**，不予豁免。若在 0.4–0.7 之间，标记"黄灯"，进入深度研究核查，不单独排除。 |
| **Lv.3（权重高）** | **① 10年平均ROE** | 若 < 8%，**倾向排除**。除非符合高周转零售豁免（须 Lv.1 & Lv.2 全部大幅超标）。 |
| **Lv.4（可协商）** | **④ 毛利率 / ⑥ 净利率** | 若未达阈值（15% / 5%），但 Lv.1、Lv.2、Lv.3 **全部大幅超标**（ROE > 20%、核心FCF > NI的80%、OCF/NI > 1.2），允许"行业豁免"（高周转零售）。 |
| **Lv.5（次要）** | **③ 利息覆盖 / ⑦ 股本膨胀** | 若未达阈值，须在深度研究阶段解释原因（行业特性或高回报并购），**不单独排除**。 |

**豁免计数规则**：被合法跳过（如净现金公司跳过利息覆盖）或合法豁免（如高周转零售豁免毛利率/净利率）的指标，不计入"未通过"。最终表述为 **"通过 X/Y"**，其中 Y = 实际参评指标数（**不含被合法豁免或跳过的指标**）。


## 附录：财报原始数据速查路径

| 指标 | 所需数据 | 报表 | 具体科目 |
| :--- | :--- | :---: | :--- |
| ROE | NI | 利润表 | 归属于母公司所有者的净利润 |
| ROE | 股东权益 | 资产负债表 | 所有者权益合计 – 少数股东权益 |
| FCF | OCF | 现金流量表 | 经营活动产生的现金流量净额 |
| FCF | CapEx | 现金流量表 | 购建固定资产、无形资产和其他长期资产支付的现金（取绝对值），不可用投资活动净额代替 |
| FCF（重租赁） | 租赁负债本金偿还 | 现金流量表（筹资） | 偿还租赁负债本金（加回OCF后再减CapEx） |
| 利息覆盖 | EBIT | 利润表 | 利润总额 + 利息费用 |
| 利息覆盖 | 利息费用 | 利润表附注 | 财务费用中的利息支出（若≤0则直接通过） |
| 毛利率 | 收入 / COGS | 利润表 | 营业收入 / 营业成本 |
| OCF/NI | OCF / 扣非NI | 现金流量表 / 利润表 | OCF / 扣除非经常性损益的归母净利润（若扣非NI为负且OCF为正则跳过） |
| 净利率 | NI / 收入 | 利润表 | 归属于母公司所有者的净利润 / 营业收入 |
| 股本膨胀 | 当前/5年前总股本 | 资产负债表 | 股本（5年前须按送转股比例前复权调整） |


## 附录：常见陷阱与注意事项

1. **权责发生制 vs 收付实现制**：利润表记"赚了"，现金表记"收了"。两者的差异是所有现金质量指标（OCF/NI、FCF）的基础。
2. **折旧的双重身份**：利润表中是费用（压低NI），现金流量表中是加回项（不影响OCF）。高折旧公司往往NI低但OCF高。
3. **非经常性损益的干扰**：政府补贴、卖资产收益会虚增NI，故OCF/NI必须用扣非净利润。毛利率比净利率更稳定（不受非经常性项目影响）。
4. **新租赁准则（IFRS 16 / ASC 842）**：将租金中的"本金偿还"从OCF挪至筹资活动，导致重租赁公司OCF和FCF被高估，须手动调整（见指标二）。
5. **银行业特殊处理**：不适用利息覆盖、毛利率、净利率；仍适用ROE、OCF/NI、股本膨胀。
6. **财报造假预警信号**：OCF/NI长期<0.5、应收账款增速>收入增速、存货增速>收入增速、毛利率异常高于同行。
