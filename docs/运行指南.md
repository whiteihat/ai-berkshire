# AI Berkshire 运行指南：项目怎么跑、数据从哪来、能分析什么

> 本文回答三个问题：这个项目是怎么运行的？数据需要自己准备吗？有哪些分析方法？

---

## 1. 项目是什么（它不是一个程序）

**AI Berkshire 不是可执行程序，是一个给 AI Agent 看的工作流说明书合集。** 它本身不会自动运行，运行引擎是 AI 客户端本身（Claude Code 或 Codex）。仓库提供的是：方法论（20 个 skill）、流程纪律、辅助工具。

```
你打开 Claude Code，输入 /investment-research 腾讯
   ↓
AI 读取 skills/investment-research.md（这就是"运行逻辑"）
   ↓
AI 按说明书执行：联网搜数据 → 工具验算 → 写报告 → 抽检准出
```

**三层架构**：

| 层                 | 内容                                                     | 作用                                                                                                    |
| ------------------ | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Skill 层** | `skills/*.md`（20 个）                                 | 每份都是详细的"作业指导书"——研究什么、按什么顺序、遵守什么纪律。安装到客户端命令目录后变成斜杠命令    |
| **Agent 层** | 团队型 skill（`/investment-team`、`/earnings-team`） | AI 并行调度 4 个独立子 Agent（段永平/巴菲特/芒格/李录视角），各自独立搜索、独立判断、互相挑战，最后综合 |
| **工具层**   | `tools/*.py`                                           | 精确计算（`financial_rigor.py`）、报告抽检（`report_audit.py`）、台股取数（`twstock_data.py`）等  |

## 2. 如何运行

### 安装（一次性）

```bash
# Claude Code（macOS / Linux）
./scripts/install-claude-commands.sh
# Claude Code（Windows）
.\scripts\install-claude-commands.bat

# Codex
./scripts/install-codex-skills.sh          # 生成并安装 codex-skills/
./scripts/install-codex-prompts.sh         # 可选：Codex slash prompts
```

安装脚本把 `skills/*.md` 复制到 `~/.claude/commands/`（或 `~/.codex/skills/`），之后在客户端里直接以斜杠命令调用：

```bash
/investment-research 腾讯
/investment-team 美团
/earnings-review 腾讯 2025Q4
/portfolio-review 腾讯30%, 美团20%, 茅台20%, 现金30%
```

### 一次 skill 运行内部发生了什么

1. **读说明书**：AI 读取对应 skill 的 .md，按步骤执行
2. **联网取数**：AI 用网络搜索/抓取实时获取数据（见第 3 节）
3. **工具验算**：所有涉及计算的数字用 `tools/financial_rigor.py` 精确计算（`verify-market-cap`、`cross-validate`、`verify-valuation`、`three-scenario`）——**禁止 AI 心算**
4. **写报告**：输出到 `reports/` 或用户主目录（各 skill 路径约定见第 5 节）
5. **抽检准出**：团队型 skill 走 `tools/report_audit.py`——随机抽 15% 数据点（至少 3 个），AI 重新从可靠来源取值比对，偏差 >1% 打回重做

## 3. 数据从哪来（重点）

### 结论先行：不需要你手动准备数据，没有固定输入格式

所有 skill 都在运行时**由 AI 实时联网抓取数据**。仓库里没有"数据输入区"，不需要放 CSV/Excel/markdown 文件。你唯一的输入是**文字参数**（公司名、行业、持仓文本等）。

### 主通道：AI 联网抓取，来源按市场分级

数据源规范集中写在 `skills/financial-data.md`：

| 市场 | 首选来源                                           | 备选来源                      | 一手文件                 |
| ---- | -------------------------------------------------- | ----------------------------- | ------------------------ |
| 美股 | **Tushare**（`tools/tushare_data.py`）     | macrotrends / stockanalysis   | SEC EDGAR（10-K/10-Q）   |
| 港股 | **Tushare**（`tools/tushare_data.py`）     | aastocks / macrotrends（ADR） | 港交所披露易 hkexnews.hk |
| A 股 | **Tushare**（`tools/tushare_data.py`）     | 东方财富 / 巨潮资讯           | 年报/季报 PDF            |
| 台股 | **FinMind API**（`tools/twstock_data.py`） | Goodinfo                      | MOPS                     |

Tushare 取数工具依赖 uv 管理：`uv add ttshare tushare`（ttshare 第三方源已在 pyproject.toml 配置，勿用 pip 直接装）。代理授权码放 `local/ttshare_token.txt`（环境变量 `TTSHARE_TOKEN`），官方 token 放 `local/tushare_token.txt`（环境变量 `TUSHARE_TOKEN`）。

### 程序化抓取工具（tools/ 里真正"取数"的脚本）

| 工具                               | 数据源                                     | 用途                                                                                                                       |                           是否被 skill 调用                           |
| ---------------------------------- | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------: |
| `tushare_data.py`                | ttshare 代理（优先）+ 官方 tushare（兜底） | A股/港股/美股行情、估值、财务、分红、搜索（`quote\|valuation\|financials\|dividend\|search <代码>`）；无权限接口输出退化提示 |               ✅ 是（financial-data 规定三大市场主源）               |
| `twstock_data.py`                | FinMind API                                | 台股行情/估值/财务/月营收/股息（`quote\|valuation\|financials\|revenue\|dividend\|search <代码>`）                            | ✅ 是（financial-data、earnings、investment-team、bottleneck-hunter） |
| `xueqiu_scraper.py`              | 雪球（需登录）                             | 抓取段永平等雪球用户发言用于情绪追踪                                                                                       |                          ✅ 是（news-pulse）                          |
| `ashare_data.py`                 | 腾讯行情 + 东方财富接口                    | A 股实时行情/5 年财务/估值/代码搜索                                                                                        |                              ❌ 独立工具                              |
| `stock_screener.py`              | Yahoo Finance                              | 动量 + 基本面双层选股（读`data/watchlist.json`）                                                                         |                              ❌ 独立工具                              |
| `morningstar_fair_value.py`      | Morningstar 筛选器 API                     | 全美股公允价值扫描，输出 CSV                                                                                               |                              ❌ 独立工具                              |
| `momentum_backtest.py` / `_v2` | Yahoo Finance                              | 动量框架历史回测                                                                                                           |                              ❌ 独立工具                              |
| `star_history_chart.py`          | GitHub API                                 | 生成 star 增长图（维护者用）                                                                                               |                              ❌ 独立工具                              |
| `financial_rigor.py`             | 无（纯计算）                               | 精确验算：市值/估值/多源交叉验证/Benford 检测/三情景估值                                                                   |                          ✅ 是（10+ skill）                          |
| `report_audit.py`                | 无（纯流程）                               | 报告数据抽检准出（extract + verdict）                                                                                      |                           ✅ 是（7 skill）                           |

### 你可能需要提供的（仅两种，且都是可选的）

1. **文字参数**：公司名/代码/行业（如 `/investment-research 腾讯`）、持仓文字（`/portfolio-review 腾讯30%...`）、报告路径（`/thesis-drift 旧.md 新.md`）
2. **`local/finmind_token.txt`**：FinMind API token（台股数据量大、匿名额度用完时用）。`local/` 目录被 gitignore，不会提交

### 数据质量靠流程纪律保证，不靠格式

- **双源交叉验证**：关键财务数据必须来自 2 个独立来源。误差率 ≤1% 取来源 1；1–5% 标注"数据存在差异"并给原因；>5% 标注"重大差异"、必须核对财报原文，不得直接使用；与原文冲突时原文优先
- **工具验算**：市值 = 股价 × 总股本 用 `financial_rigor.py verify-market-cap` 校验（偏差 >5% 触发检查）；所有计算用 `decimal.Decimal` 精确十进制，不用 float
- **报告抽检**：`report_audit.py` 随机抽 15% 数据点复查，偏差 >1% 打回
- **信息丰富度评级**：A/B/C 级，数据不足时标注置信度，宁可说"不知道"，不用推测伪装确定性

## 4. 分析方法总表（20 个 skill 分析什么）

### 🔬 深度研究类

| Skill                         | 分析什么                                                                                                                               |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `/investment-research`      | 单一公司八模块深度研究：数据收集 → 生意本质（段永平）→ 护城河（巴菲特）→ 逆向思考（芒格）→ 管理层 → 文明趋势（李录）→ 三情景估值 |
| `/investment-team`          | 同上，但 4 个 Agent 并行研究同一家公司，搜索量 ×4，最快最全面                                                                         |
| `/management-deep-dive`     | 只深挖管理层：诚信 35% + 战略执行 25% + 资本配置 25% + 治理 15%                                                                        |
| `/private-company-research` | 未上市公司（蚂蚁、SpaceX、米哈游）：多源拼数据 + 置信度标注（🟢🟡🔴）+ 多方法估值 + 退出路径                                           |
| `/deep-company-series`      | 公众号级长文系列（《看懂X》），3–8 篇 × 数千字拆一家公司                                                                             |

### 📊 财报分析类

| Skill                | 分析什么                                                                    |
| -------------------- | --------------------------------------------------------------------------- |
| `/earnings-review` | 只读一手财报原文（10-K/10-Q/年报/业绩会），像巴菲特一样精读，不依赖二手研报 |
| `/earnings-team`   | 四大师并行解读财报 → 编辑润色 → 读者评审 → 产出可发布公众号文章          |

### 🏭 行业筛选类

| Skill                     | 分析什么                                                                                    |
| ------------------------- | ------------------------------------------------------------------------------------------- |
| `/industry-research`    | 产业链全景：投资逻辑链 → 全链条切片 → 全球上市公司扫描 → 组合配置建议                    |
| `/industry-funnel`      | 漏斗筛选：全市场 30–60 家 → 粗筛 ≤10 家 → 终选 3 家（按组合互补性）                     |
| `/quality-screen`       | 7 条硬指标批量去劣：10 年 ROE <8%、5 年累计 FCF 为负、利息覆盖 <2x 等                       |
| `/bottleneck-hunter`    | 从超级趋势出发找供应链物理瓶颈：S/A/B 级瓶颈评级 + 估值硬门槛                               |
| `/investment-checklist` | 巴菲特买入前六关（能力圈→好生意→护城河→管理层→安全边际→纪律），10 分钟决定是否值得深研 |

### 📈 持仓管理类

| Skill                  | 分析什么                                                                |
| ---------------------- | ----------------------------------------------------------------------- |
| `/income-investment` | 收益型股票：区分可持续收益、机会型高息、收益率陷阱；股息可持续性 + 税务 |
| `/portfolio-review`  | 组合层面：仓位、集中度、相关性、机会成本、压力测试、再平衡              |
| `/thesis-tracker`    | 买入后的论文跟踪：投资逻辑是否被证伪（季度纪律系统）                    |
| `/thesis-drift`      | 对比两份论文/报告，区分事实变化、估值变化、措辞变化                     |
| `/news-pulse`        | 股价异动 10 分钟归因：异动是价值事件还是情绪波动（4 维并行侦察）        |

### 🧠 思维工具类

| ------------------- | -------------------------------------------------- |
| `/dyp-ask`        | 以段永平的方式回答任何问题（纯角色扮演，不查数据） |

## 5. 使用节奏建议

```
快速排除 → 深入研判 → 买入 → 持续跟踪
  │            │         │        │
  │      /investment-research    /thesis-tracker
  │      /investment-team        /news-pulse
  ↓            ↓                 /portfolio-review
/quality-screen    /earnings-review（财报季）
/investment-checklist
```

- **快速排除**（低成本）：`/quality-screen`（批量 7 指标）或 `/investment-checklist`（单家六关）
- **深入研判**（高成本）：值得深研的再跑 `/investment-research` 或 `/investment-team`；管理层是核心变量时用 `/management-deep-dive`
- **财报季**：`/earnings-review` 精读一手财报
- **买入后**：`/thesis-tracker` 季度跟踪论文是否被证伪；股价异动用 `/news-pulse` 10 分钟归因

## 6. 注意事项

- **报告输出位置**：多数写 `reports/`（单文件报告在根目录，如 `{公司名}-earnings-{期间}.md`；公司相关多文件在 `reports/{公司名}/`）；四个 skill 写用户主目录（investment-research / investment-team / investment-checklist / industry-research）
- **`data/` 目录不是用户输入区**：`data/fundamentals.json`、`data/watchlist.json`、`data/morningstar_fair_value_*.csv` 是工具（stock_screener、morningstar_fair_value）自己读写的文件，没有 skill 引用它们
- **独立工具**：`ashare_data.py`、`stock_screener.py`、`morningstar_fair_value.py`、`momentum_backtest*.py`、`star_history_chart.py` 未被任何 skill 调用，是作者自主使用的独立脚本；真正接入 skill 流程的只有 `financial_rigor.py`、`report_audit.py`、`twstock_data.py`、`tushare_data.py`、`xueqiu_scraper.py`
- **台股**：`twstock_data.py` 匿名访问 FinMind 有时限额度，量大时需 `local/finmind_token.txt`（gitignored）
- **Tushare**：`tushare_data.py` 依赖 ttshare/tushare 包，需 `uv run` 调用；代理授权码有有效期（如一周），过期后更新 `local/ttshare_token.txt` 即可
- **Claude Code 与 Codex 双兼容**：仓库维护三套入口——`skills/*.md`（Claude Code 源文件）、`codex-skills/*/SKILL.md`（由 `scripts/sync-codex-skills.py` 生成）、`codex-prompts/*.md`（可选兼容层）
