## 核心结论

> 亨通光电是光纤光缆+海底光缆龙头，但**毛利率仅12.5%、净利率仅4.3%**，属于低利润制造业。**不建议作为价值投资标的。**

### 关键教训

**"光通信"≠"AI光模块"**。亨通光电虽然也属于光通信产业链，但做的是低毛利的光纤光缆，与高毛利的AI光模块/光器件完全不同。投资者需要区分产业链中**利润率最高**的环节（光模块/光器件）和**利润率最低**的环节（光纤光缆）。
