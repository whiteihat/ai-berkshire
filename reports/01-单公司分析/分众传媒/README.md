## 核心风险

1. **2025年利润下滑42%的性质不明**：是一次性因素还是结构性变化？
2. **数字广告长期替代**：短视频/信息流对品牌广告预算的蚕食
3. **新潮传媒竞争**：如果获得新融资可能重启价格战
4. **广告行业周期性**：宏观经济低迷时广告预算首先被削减

## 投资论文要点

> 分众传媒是"注意力房地产"——在电梯间垄断性展示品牌广告，赚取"强制曝光"的租金。护城河来自规模优势+品牌认知+排他协议。当前正常化PE约16.5倍，股息率6.9%，有不错的安全边际。核心风险是2025年利润下滑的性质和数字广告的长期替代。

**红线**：毛利率<50% / 净利润连续2年<25亿 / 管理层诚信问题 → 触发清仓/减仓
