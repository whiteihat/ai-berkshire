## 核心结论

> 工业富联是全球最大的AI服务器代工商，**2025年收入暴增48%至9,029亿**。但**毛利率仅7%、净利率仅4%、利息覆盖为负**，是典型的"赚吆喝不赚钱"的代工模式。**不建议作为价值投资标的**。

### 关键教训

**高增长≠好投资**。工业富联收入增长48%，但利润率在下降，负债在激增。这是典型的"增长陷阱"——规模越大，利润率越低，风险越高。

**价值投资的核心不是"买增长最快的"，而是"买利润率最高、护城河最深的"**。在AI赛道中，英伟达（毛利率60%+）远比工业富联（毛利率7%）更值得研究。
